Show HN: Curvely – A graphing calculator that stays on your device

I needed a grapher for Pre-Calc that opened instantly, worked offline and did not want an account. Curvely is that. Type equations, they plot together, pan and zoom, everything computed locally. There is also an API and an MCP endpoint if you want to graph from code or from an AI assistant. Web at curvely.heyitsmejosh.com, source on GitHub.
